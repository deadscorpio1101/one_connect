# one_connect

手表应用的法律文档位于 `docs/`，包含隐私政策、个人信息收集清单和用户服务条款与条件。

## GitHub Pages 发布

将本地提交推送到 `origin/main` 后，打开仓库的 **Settings → Pages**。
在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**，
选择 `main` 分支和 `/docs` 目录，然后点击 **Save**。

使用默认域名部署后，可访问以下页面。

- [文档目录](https://deadscorpio1101.github.io/one_connect/)
- [隐私政策](https://deadscorpio1101.github.io/one_connect/privacy.html)
- [个人信息收集清单](https://deadscorpio1101.github.io/one_connect/personal.html)
- [用户服务条款与条件](https://deadscorpio1101.github.io/one_connect/terms.html)
